# 🎥 MovieScope

A React app for searching and exploring movies in real time. Search the OMDb catalog, browse results with posters and ratings, and dive into details for any title — all through a clean, responsive interface.

## 🚀 Live Demo

[moviescope-react-app.vercel.app](https://moviescope-react-app.vercel.app)

## ✨ Features

- **Live movie search** powered by the [OMDb API](https://www.omdbapi.com/)
- **Dedicated pages** for home, search results, and individual movie details (React Router)
- Responsive layout that works from mobile to desktop
- Deployed on Vercel

## 🛠️ Tech Stack

- [React 19](https://react.dev/)
- [React Router 7](https://reactrouter.com/)
- OMDb API
- Create React App build tooling

## 💻 Run Locally

```bash
git clone https://github.com/cornious-on-the-cob/moviescope-react-app
cd moviescope-react-app
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).
